# cevdet.ch

Cevdet's portfolio. This repository is the single source for
[cevdet.ch](https://cevdet.ch/) and for the CV, built with Astro as a static
site and deployed by Cloudflare Pages.

## Requirements

- Node.js 24.8.0 or newer
- pnpm, pinned in `package.json`
- Python 3.12 or newer, for rendering the CV: `pip install -r requirements.txt`

## Setup

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Commands

| Command | Purpose |
| --- | --- |
| `pnpm dev` | Run the site locally |
| `pnpm verify` | Run every check: types, tests, a fresh build and the output gates |
| `pnpm fetch-facts` | Refresh `src/facts/` from GitHub and npm |
| `pnpm cv:private` | Render the full CV, including the fields kept out of the public build |
| `pnpm lighthouse` | Build and audit performance, accessibility, best practices and SEO |
| `pnpm build` | Build the static site into `dist/` |
| `pnpm preview` | Preview the production build |

`pnpm fetch-facts` needs a token with read access to the GitHub API:

```sh
GITHUB_TOKEN=$(gh auth token) pnpm fetch-facts
```

`pnpm lighthouse` needs a Chrome or Chromium binary. It honours `CHROME_PATH`
when the default is not on the system:

```sh
CHROME_PATH=/path/to/chrome pnpm lighthouse
```

## Story and Facts

Page copy, Work entries, the profile, skills and the rest of the site's
content live in `src/content/`, written by hand.

Everything that is a version, a date or a count lives in `src/facts/`. Its
`snapshot.json` is generated by `pnpm fetch-facts` and refreshed on a weekly
schedule in CI. Never edit `src/facts/` by hand; a hand-written fact is a bug.

## The CV

The public CV is built from the same content and published at `/cv.pdf`.
A fuller version, with fields that don't belong on the public site (full
name, phone, location), renders locally from `cv.private.env`, copied from
`cv.private.env.example` and filled in. Its output lives in `private/` and
is never committed or published.

## Verification

`pnpm verify` runs type checks, the test suites, a build and the output
gates, and must pass before a change ships. `pnpm lighthouse` runs the
performance, accessibility, best-practices and SEO budgets against a local
preview build. Both run in CI on every push and pull request, alongside a
link check of the built site.
